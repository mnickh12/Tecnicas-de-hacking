# Prácticas y Laboratorios de Seguridad

Este repositorio centraliza los proyectos y prácticas de laboratorio desarrollados para la asignatura. Contiene diferentes entornos, apuntes y pruebas de concepto orientadas a la seguridad informática y el hacking ético.

## Estructura del Repositorio

El contenido está dividido en los siguientes tres módulos principales:

* **[`/Laboratorio-hacking`](./Laboratorio-hacking):** Configuración y preparación del entorno de pruebas. Incluye detalles sobre el despliegue de máquinas virtuales, redes aisladas y configuración de herramientas fundamentales para auditorías.
* **[`/Mitm-y-suplantacion`](./Mitm-y-suplantacion):** Prácticas enfocadas en la interceptación de tráfico de red. Contiene pruebas de concepto sobre ataques Man-in-the-Middle (MITM), ARP Spoofing, envenenamiento DNS y análisis de paquetes.
* **[`/Reconocimiento-activo`](./Reconocimiento-activo):** Técnicas para la fase de recolección de información e interacción directa con los objetivos. Incluye escaneo de puertos, enumeración de servicios, versiones y mapeo de la superficie de ataque.

## Entorno y Herramientas Comunes

A lo largo de los distintos repositorios se hace uso de herramientas estándar de la industria, tales como:
* Distribuciones orientadas a seguridad (Kali Linux / Parrot OS)
* Nmap
* Wireshark / tcpdump
* Herramientas de interceptación (Ettercap, Bettercap, etc.)
